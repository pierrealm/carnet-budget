# Carnet

Appli web gratuite de budget personnel. Site statique (HTML, CSS, JS), sans étape de build.

- `index.html` : accueil
- `app.html` : l'application
- Pages légales : `mentions-legales.html`, `confidentialite.html`, `cgu.html`

## Déploiement

Vercel, projet `carnet-budget`, framework « Other », sans commande de build, dossier de sortie `.` (racine).

Le suivi de la conformité est dans `CONFORMITE.md`.
